# 优先核查事件 HLS 提取摘要

运行时间：2026-10-28

## 数据范围

- 事件主表：实施方案“优先核查30条”。
- 已定位并进入 Earth Engine 计算：20 个事件。
- 其中 18 个为“乡镇 + 小班号”匹配到的小班面，2 个为严格配准实测点辅助定位。
- 仍有 10 个候选事件缺少可靠空间几何，未伪造边界，也未纳入本次遥感统计。
- 数据源：NASA HLS L30/S30 v002，30 m；时间范围 2018-01-01 至 2025-12-31。

## 计算口径

- EVI 为主指标；NBR 和 NDMI 为辅助指标。
- 前窗口：事件日前 3 年至事件日前 30 天，并按事件月份前后 1 个月筛选同季节影像。
- 后窗口：事件日后 30—120 天，不按事件月份截断，以减少冬季或雨季清晰影像不足造成的缺测。
- Fmask bits 1—5 掩膜；HLS v002 波段在 Earth Engine 中已经是反射率单位，没有重复乘 `0.0001`。
- 恢复程度和恢复时间暂不计算，因为实施方案尚未给出事件级恢复目标。

## 当前结果

- 20/20 个事件有前后有效像元，`metric_status=valid_pre_post`。
- EVI 相对变化范围：`-43.33%` 至 `+61.61%`。
- dNBR 范围：`-0.1028` 至 `+0.0901`。
- 这些变化值是状态变化指标和抵抗力代理，不能直接解释为生态损失或恢复效果。
- 由于后窗口跨越事件后 30—120 天，物候差异可能影响 EVI 方向；A 类事件仍需抽查原始影像，并结合计划性采伐台账判断。
- `point_fallback_measured` 事件不用于遥感面积统计，尤其需要补充正式小班边界后再进入 A 类分析。

## 输出文件

- `priority30_hls_event_metrics.csv`：事件级表格。
- `priority30_hls_event_metrics.geojson`：含事件几何和事件级指标。
- `hls_resilience_timeseries.js`：GEE Code Editor 复算和 Drive 导出脚本。
- `run_gee_extract.py`：使用本地 GeoJSON 直接调用 Earth Engine Python API 的脚本。
